
## NPP / @oresoftware/npp

[![Join the NPP chat on Matrix](https://img.shields.io/badge/chat-Matrix-0dbd8b?logo=matrix)](https://matrix.to/#/#oresoftware_npp:gitter.im)

>  NPP goes hand-in-hand with NLU (npm-link-up)
>


### Caveats / Disclaimer

* Currently only works with Git
* You need Git version > 2.7.0 on your local machine
